# Blinkit Sales Analysis Dashboard – Power BI

## 📊 Project Overview

This project presents an interactive *Blink it Sales Analysis Dashboard* built using Microsoft Power BI

The dashboard provides insights into sales performance, outlet characteristics, item categories, fat content, outlet locations, and outlet establishment trends.

## 🎯 Objectives

- Analyze overall Blink it sales performance
- Understand sales distribution across different outlet types
- Analyze sales based on item categories
- Compare outlets based on size and location
- Study the impact of item fat content on sales
- Analyze outlet establishment trends over the years
- Provide an interactive dashboard for business decision-making

| KPI | Value |
|---|---:|

## 📈 Dashboard Features

### 1. Sales Overview
Displays key metrics such as:
- Total Sales
- Average Sales
- Number of Items
- Average Rating

### 2. Outlet Establishment
Shows the sales trend based on the year in which outlets were established.

### 3. Fat Content Analysis
Analyzes sales based on different item fat-content categories such as:
- Low Fat
- Regular

### 4. Item Type Analysis
Compares sales across different product categories, including:
- Fruits and Vegetables
- Snack Foods
- Household
- Frozen Foods
- Dairy
- Canned
- Baking Goods
- Health and Hygiene
- Soft Drinks
- Others

### 5. Outlet Size Analysis
Analyzes sales distribution across:
- Small
- Medium
- High

### 6. Outlet Location Analysis
Compares outlet performance across different location tiers:
- Tier 1
- Tier 2
- Tier 3

### 7. Outlet Type Analysis
Provides a detailed comparison of different outlet types using:
- Total Sales
- Number of Items
- Average Sales
- Average Rating
- Visibility

## 📊 Dashboard Filters

The dashboard includes interactive filters for:

- Outlet Location Type
- Outlet Size
- Item Type
- Fat Content
- Outlet Type

These filters allow users to drill down into specific segments of the business.

## 💡 Key Insights

The dashboard helps identify:

- High-performing outlet types
- Sales contribution by product category
- Differences in performance across outlet locations
- Relationship between outlet size and sales
- Sales contribution of different fat-content categories
- Changes in outlet performance over time
